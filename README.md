### 👨‍💻 Sobre mí

Soy **Full Stack Software Engineer** con **4 años de experiencia** construyendo y manteniendo productos web y mobile en producción para **Retail, Fintech, EdTech y HR-Tech**.

Trabajé en la app de Carrefour Argentina (+1M de descargas), en el core de una billetera virtual con NestJS, TypeORM y MySQL, y en flujos end-to-end que atraviesan varios repositorios para la solicitud y evaluación de candidatos.

Mi enfoque es separar la lógica de negocio de la interfaz, modernizar código legacy con migraciones incrementales a TypeScript y estandarizar APIs y manejo de errores, para que los productos sean más fáciles de mantener y de hacer crecer.
